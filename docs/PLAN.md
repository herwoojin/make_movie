## 2. M0 — 기술 검증 (1주차) ⚠️ 가장 중요

여기서 막히면 나머지 설계가 전부 무의미해진다. **다른 코드를 짜기 전에 이것부터.**

### 스파이크 1: cross-origin isolation
- 목표: Netlify에 배포한 상태에서 `self.crossOriginIsolated === true` (`scripts/check-deploy.mjs`)
- 실패 시 대안: COEP를 `credentialless`로 완화 → 그래도 안 되면 단일 스레드 ffmpeg로 설계 축소
- 소요: 반나절

### 스파이크 2: WebCodecs 인코딩 왕복
- 목표: 5초짜리 mp4 → 디코드 → Canvas에 사각형 하나 그리기 → 재인코딩 → 재생 가능한 mp4
- 이게 되면 모자이크·자막 번인 설계가 전부 성립한다
- 실패 시 대안: ffmpeg.wasm 단독 경로로 설계 변경 (성능 목표를 3배 낮춤)
- 소요: 1~2일

### 스파이크 3: 로컬 Whisper 단어 타임스탬프
- 목표: 1분 한국어 오디오 → transformers.js Whisper → **단어 단위** 타임스탬프
- 이게 안 되면 "추임새 제거"가 불가능하다 (무음 컷만 가능)
- 실패 시 대안: BYOK(Groq) 필수로 변경, 로컬은 세그먼트 자막만 제공
- 소요: 1~2일

### M0 종료 판정
| 결과 | 조치 |
|---|---|
| 3개 다 성공 | 계획대로 진행 |
| 스파이크 2 실패 | 성능 목표 하향, M4(모자이크) 방식을 프레임 시퀀스 방식으로 확정 |
| 스파이크 3 실패 | 추임새 제거를 P2로 강등, 무음 컷에 집중 |
| 스파이크 1 실패 | 멀티스레드 포기, 처리 가능 영상 길이를 10분으로 하향 |

## 3. 마일스톤별 상세

### M1 — 편집기 뼈대 (2주차)
```
목표: "영상을 넣고, 필요 없는 부분을 자르고, 내보낸다"가 되는 최소 앱
```
- 저장 계층(OPFS + Dexie) 완성
- 임포트 → 파형 → 타임라인 → 수동 분할/삭제 → 내보내기
- Undo/Redo
- **의도적으로 빼는 것**: 자막, 모자이크, 자동 컷, 로그인, 도구함

M1이 끝나면 이미 "쓸 수 있는 앱"이다. 여기서 본인이 실제 영상 하나를 편집해 보고, 불편한 점을 적어서 M2 계획에 반영한다.

### M2 — 자동 컷 편집 (3주차)
```
목표: 20분 강의 영상의 무음 구간이 자동으로 잡힌다
```
- 무음 감지 알고리즘 + 파라미터 UI
- 제안 목록 + 미리듣기 + 개별 토글
- EDL 적용 + 되돌리기
- **검증**: 실제 자기 영상 3개로 테스트. 수동 보정이 필요한 컷이 15% 이하인지 세어 본다.

### M3 — 자막 (4~5주차, 2주 배정)
```
목표: 자막 자동 생성 → 고치기 → 스타일 → 영상에 굽기
```
가장 크고 가장 오래 걸리는 마일스톤이다. 3단계로 쪼갠다.
- 4주차 전반: STT 어댑터 (로컬 Whisper + Groq BYOK) + 필러 사전
- 4주차 후반: 1단계 편집(글자) + 2단계 편집(시간)
- 5주차: 스타일 패널 + 프리셋 + ASS 생성 + 번인 + SRT 내보내기
- **주의**: 미리보기 렌더와 내보내기 렌더를 같은 함수로 만들 것. 이걸 어기면 5주차 내내 "미리보기와 다르게 나온다" 버그를 잡게 된다.

### M4 — 얼굴 모자이크 (6주차)
```
목표: 영상 속 얼굴이 자동으로 따라다니며 가려진다
```
- 살핌ON의 MediaPipe 래퍼·모자이크 렌더를 가져와서 재사용 → 신규 개발은 트래킹과 인물별 예외만
- 사진 일괄 모자이크는 같은 코드로 하루면 붙는다
- **검증**: 사람 2명 이상 나오는 영상, 옆모습·가림 있는 영상

### M5 — 도구함 (7주차)
```
목표: 편집기와 별개로 단독으로 쓰이는 작은 도구들
```
- 일괄 GIF 변환 / 화면 녹화 → GIF·MP4 / 오디오 추출 / 이미지 리사이즈·압축·포맷 변환
- 전부 이미 만든 인코더·저장 계층을 쓰므로 각각 반나절 수준
- 도구함은 **유입 경로**이기도 하다. "GIF 변환기"로 들어온 사람이 편집기를 발견하게 한다.

### M6 — 다듬기·배포 (8주차)
- 온보딩: 랜딩에서 샘플 영상으로 30초 체험
- 브라우저 미지원 안내 정교화
- PWA (오프라인 동작 — 어차피 전부 클라이언트라 자연스럽다)
- 성능 튜닝: TRD 6장 예산 대비 측정, 초과 항목 개선
- 접근성: 키보드 단축키, 포커스 순서, 대비
- Firebase Google 로그인 + 프리셋·추임새 사전 동기화 (선택 기능이므로 마지막)
- 실사용자 3명 테스트 → 막히는 지점 수정

## 4. 작업 순서 원칙

```
아래 → 위 순서로 쌓는다. 위에서부터 만들면 반드시 다시 짜게 된다.

  ⑤ UI 패널 (AutoCutPanel, SubtitlePanel, MosaicPanel)
  ④ Zustand 스토어 + 명령/되돌리기
  ③ Worker 래퍼 (진행률·취소)
  ② 순수 로직 (silence, edl, tracker, subtitle) ← 테스트 여기 집중
  ① 저장 계층 (OPFS, Dexie)
  ⓪ 환경 (COOP/COEP, 기능 감지)
```

각 기능마다 이 순서를 지킨다. UI를 먼저 만들고 싶은 유혹이 크지만, 순수 로직이 확정되기 전에 UI를 만들면 로직이 바뀔 때마다 UI를 다시 만들어야 한다.

## 5. 검증 게이트

각 마일스톤 종료 시 아래를 통과해야 다음으로 넘어간다.

| 게이트 | 항목 |
|---|---|
| G1 코드 | `npm run typecheck` 무오류, `npm run lint` 무경고 |
| G2 테스트 | 순수 로직 커버리지 90% 이상, E2E 시나리오 통과 |
| G3 성능 | TRD 6장 예산 대비 측정치 기록 (초과해도 기록은 남긴다) |
| G4 실사용 | **본인이 실제 영상 1개를 그 기능으로 편집해 본다** |
| G5 문서 | TASK.md 체크박스 갱신, 설계 변경 시 TRD/ERD 갱신 |

G4가 가장 중요하다. 테스트는 통과하는데 실제로는 못 쓰는 기능이 나오는 걸 막는 유일한 방법이다.

## 6. 리스크 대응

| 리스크 | 조기 신호 | 대응 |
|---|---|---|
| 브라우저 메모리 초과로 탭 크래시 | 10분 영상에서 처리가 느려짐 | 청크 크기를 절반으로, 처리 가능 길이 상한을 UI에 명시 |
| M3(자막)이 2주를 넘김 | 5주차 중반까지 스타일 패널 미착수 | 번역 자막·TTS를 v2로 미루고 핵심만 마감 |
| WebCodecs 코덱 미지원 사용자 다수 | 실사용 테스트에서 폴백 비율 높음 | ffmpeg 경로 최적화에 시간 재배분 |
| Whisper 모델 다운로드에 사용자 이탈 | 체험자가 자막 생성 전에 나감 | BYOK를 기본 안내로 승격, 로컬은 "인터넷 없이도 되는 방법"으로 포지셔닝 |
| 혼자 하다 8주가 12주가 됨 | 2주 연속 마일스톤 지연 | M5(도구함)를 통째로 잘라낸다. 도구함은 없어도 제품이 성립한다 |

**잘라낼 순서 (일정이 밀릴 때)**: TTS → 번역 자막 → 도구함 → Firebase 로그인 → 사진 일괄 모자이크
**절대 못 자르는 것**: 임포트, 타임라인, 무음 자동 컷, 내보내기
