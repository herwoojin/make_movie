# PRD — 편집ON (EditON)

> 브라우저에서 100% 무료로 돌아가는 초간단 영상 편집 웹앱
> 문서 버전 v1.0 / 작성일 2026-09-13

---

## 1. 배경

유튜브 영상에서 소개된 "돈 내고 쓰던 기능을 직접 만들었다"는 사례의 핵심은 **비싼 올인원 편집 프로그램의 기능 중, 내가 실제로 쓰는 5~6개만 뽑아서 내 방식대로 만든 것**이다. 원본 사례에서 영상 편집과 직접 관련된 기능은 다음과 같다.

| 원본 사례 기능 | 편집ON 반영 |
|---|---|
| 음성 기반 자동 컷 편집 (무음·추임새 제거) | ✅ 핵심 기능 |
| 자막 자동 생성 + 2단계 편집 + 스타일 커스터마이징 | ✅ 핵심 기능 |
| 영상/사진 얼굴 자동 추적 모자이크 | ✅ 핵심 기능 |
| 일괄 GIF 변환 / 화면 녹화 GIF / 사진 편집 | ✅ 도구함으로 통합 |
| 해외 영상 한국어 자막 자동 생성 | ✅ 선택 기능 (BYOK) |
| 감정 표현 TTS (목소리 학습) | ⚠️ 축소 반영 (아래 6장 참조) |
| A4 라벨 인쇄 / 홈페이지 SEO / 블로그 자동화 | ❌ 범위 외 (영상 편집 아님) |

### 왜 "웹앱"이고 왜 "무료"인가
- **설치 없음**: 유튜버·1인 크리에이터가 링크만 열면 바로 편집.
- **서버 비용 0원**: 영상은 서버로 업로드하지 않고 **브라우저 안에서만** 처리한다. 이것이 무료를 유지하는 유일한 방법이다. (10분짜리 1080p 영상 1개만 서버로 올려도 무료 티어는 즉시 초과된다.)
- **프라이버시**: 얼굴이 나오는 매장 영상·가족 영상도 외부로 나가지 않는다.

## 2. 제품 목표

**한 줄 정의**: 유튜브 영상 하나를 올리면, 무음과 추임새가 잘리고, 자막이 붙고, 얼굴이 가려진 완성본이 나오는 무료 웹 편집기.

### 성공 기준 (출시 3개월)
| 지표 | 목표 |
|---|---|
| 첫 방문 → 결과물 내보내기 완료율 | 40% 이상 |
| 10분 영상 자동 컷 편집 처리 시간 | 3분 이내 (WebCodecs 경로 기준) |
| 자동 컷 편집 후 수동 보정 필요 컷 비율 | 15% 이하 |
| 얼굴 검출 누락률 (정면·측면 기준) | 5% 이하 |
| 월 운영 비용 | **0원** (Netlify Free + Firebase Spark 범위 내) |

### 비목표 (하지 않을 것)
- 프리미어/파이널컷 대체 — 멀티 트랙 합성, 키프레임 애니메이션, 컬러 그레이딩 없음
- 팀 협업, 실시간 공동 편집
- 서버 렌더링 팜, 클라우드 저장소
- 4K·1시간 이상 장편 처리 (브라우저 메모리 한계)

## 3. 타겟 사용자

### P1. 롱폼 유튜버 "민수" (주 사용자)
- 20~40분짜리 강의형 영상을 주 2회 업로드
- 편집 시간의 70%가 "말 안 하는 구간 자르기 + 어…음… 지우기"
- Vrew 유료 결제 중이지만 자막 스타일이 마음에 안 듦
- **핵심 니즈**: 자동 컷 + 자막이 한 번에, 결과가 마음에 안 들면 수동으로 즉시 되돌리기

### P2. 현장 사진·영상 공유자 "지훈"
- 매장·현장 점검 영상을 사내에 공유해야 하는데 손님 얼굴이 찍힘
- 유료 모자이크 툴을 쓰기엔 결재가 번거롭고, 영상을 외부 서버에 올리는 것도 부담
- **핵심 니즈**: 얼굴만 자동으로 가려서 내보내기, 영상이 PC 밖으로 안 나가는 것

### P3. 가끔 쓰는 일반 사용자 "은영"
- 영상 자르기, GIF 만들기 정도만 1년에 몇 번
- **핵심 니즈**: 회원가입 없이 바로 쓰기

## 4. 사용자 스토리

### Epic A. 프로젝트 & 타임라인
- A-1. 사용자는 영상 파일을 드래그해서 놓으면 프로젝트가 만들어진다.
- A-2. 사용자는 타임라인에서 재생·정지·구간 이동을 할 수 있다.
- A-3. 사용자는 재생헤드 위치에서 클립을 분할하고, 클립을 삭제·복원할 수 있다.
- A-4. 사용자는 브라우저를 닫았다 켜도 작업 중이던 프로젝트를 이어서 할 수 있다.
- A-5. 사용자는 Ctrl+Z로 최근 20단계까지 되돌릴 수 있다.

### Epic B. 자동 컷 편집 (핵심)
- B-1. 사용자는 "무음 자동 감지" 버튼을 눌러 말이 없는 구간을 자동으로 찾는다.
- B-2. 사용자는 감지 기준(무음 임계 dB, 최소 무음 길이, 앞뒤 여백)을 슬라이더로 조절하고 결과를 즉시 미리본다.
- B-3. 사용자는 감지된 컷 목록을 보고 개별로 "살리기/자르기"를 토글한다.
- B-4. 사용자는 "추임새 제거"를 켜서 어·음·그·저기·아 같은 필러 단어를 자동으로 잘라낸다.
- B-5. 사용자는 필러 단어 사전을 직접 추가·삭제할 수 있다.
- B-6. 사용자는 컷 지점을 미리듣기로 확인하고, 잘림이 어색하면 경계를 1프레임 단위로 밀 수 있다.

### Epic C. 자막
- C-1. 사용자는 "자막 생성"을 눌러 음성을 텍스트로 변환한다. (엔진 선택: 브라우저 내장 / BYOK API)
- C-2. 사용자는 **1단계 편집**에서 문장 단위로 오타를 고치고 문장을 합치거나 나눈다.
- C-3. 사용자는 **2단계 편집**에서 각 자막의 시작·끝 시간을 타임라인에서 드래그로 맞춘다.
- C-4. 사용자는 글꼴, 크기, 색상, 외곽선, 그림자, 배경 박스, 위치, 줄 수를 조절한다.
- C-5. 사용자는 자막 스타일을 프리셋으로 저장하고 다음 프로젝트에서 불러온다.
- C-6. 사용자는 자막을 영상에 굽거나(번인), .srt / .vtt 파일로 내려받는다.
- C-7. (선택) 사용자는 외국어 영상의 자막을 한국어로 번역한다.

### Epic D. 얼굴 자동 모자이크
- D-1. 사용자는 "얼굴 자동 가리기"를 눌러 영상 전체의 얼굴을 검출·추적한다.
- D-2. 사용자는 모자이크 패턴(픽셀·블러·검은 박스·이모지), 강도, 영역 크기를 조절한다.
- D-3. 사용자는 특정 인물(예: 본인)을 "가리지 않기"로 예외 처리한다.
- D-4. 사용자는 검출이 놓친 구간에 수동으로 사각형을 그려 추가한다.
- D-5. 사용자는 사진 여러 장을 한 번에 올려 얼굴을 일괄 모자이크 처리한다.

### Epic E. 변환 도구함
- E-1. 사용자는 영상 여러 개를 한 번에 GIF로 변환한다. (해상도·FPS·길이 지정)
- E-2. 사용자는 화면을 녹화해서 바로 GIF/MP4로 저장한다.
- E-3. 사용자는 영상에서 구간을 지정해 MP3(오디오)만 추출한다.
- E-4. 사용자는 이미지 크기 조절·자르기·포맷 변환·용량 압축을 한다.

### Epic F. 내보내기
- F-1. 사용자는 해상도·비트레이트·포맷(MP4/WebM)을 고르고 내보낸다.
- F-2. 사용자는 진행률과 예상 남은 시간을 본다.
- F-3. 사용자는 내보내기 중에도 다른 탭을 봐도 작업이 계속된다.
- F-4. 사용자는 편집 결정만 담긴 프로젝트 파일(.editon.json)을 내보내고 다시 불러올 수 있다.

### Epic G. 계정 (선택)
- G-1. 사용자는 **로그인 없이** 모든 편집 기능을 쓸 수 있다.
- G-2. 사용자는 로그인하면 자막 스타일 프리셋과 설정을 기기 간에 동기화한다.

### UX 원칙
1. **큰 버튼, 한국어 평문**: "무음 임계값 -35dB" 옆에 "조용한 구간을 얼마나 민감하게 잡을지" 설명을 항상 같이 쓴다.
2. **되돌릴 수 있다는 확신**: 자동 처리는 전부 "제안"으로 표시하고, 적용 전에 목록으로 보여준다. 원본 파일은 절대 수정하지 않는다.
3. **기다리게 하지 않기**: 무거운 작업은 진행률 + 취소 버튼을 반드시 붙인다.
4. **처음 온 사람도 3분 안에 결과물**: 랜딩에서 샘플 영상으로 바로 체험 가능.

## 6. 기능 우선순위와 솔직한 한계

### 우선순위
| 순위 | 기능 | 근거 |
|---|---|---|
| P0 | 프로젝트·타임라인·수동 컷·내보내기 | 없으면 아무것도 안 됨 |
| P0 | 무음 자동 컷 편집 | 사용자가 가장 원하는 것, 기술 난도 낮음 |
| P1 | 자막 생성·2단계 편집·스타일 | 두 번째로 원하는 것, STT 의존 |
| P1 | 얼굴 자동 모자이크 | 대체재가 비쌈, 차별점 |
| P2 | 변환 도구함 (GIF·화면녹화·이미지) | 부가가치, 구현 쉬움 |
| P3 | 번역 자막, TTS 내레이션 | 외부 API 의존, 무료 유지 어려움 |

### 미리 인정하고 가는 한계
| 한계 | 내용 | 대응 |
|---|---|---|
| **영상 길이** | 브라우저 메모리상 1080p 기준 20분 정도가 현실적 상한 | 20분 초과 시 경고 + "구간 나눠 처리" 안내 |
| **처리 속도** | ffmpeg.wasm은 네이티브 대비 5~10배 느림 | WebCodecs 하드웨어 경로를 1순위, wasm은 폴백 |
| **브라우저** | iOS Safari는 SharedArrayBuffer·OPFS 제약이 큼 | 데스크톱 Chrome/Edge 권장, 미지원 시 랜딩에서 명확히 안내 |
| **목소리 학습 TTS** | 무료·브라우저 내에서 음성 복제는 불가능 | 브라우저 내장 TTS(무료, 감정 표현 제한적)만 제공하고 그렇게 표기 |
| **번역 품질** | 무료 로컬 번역 모델은 품질이 낮음 | 사용자가 자기 API 키를 넣는 BYOK 방식으로만 제공 |
| **저작권** | 유튜브 영상 다운로드 기능은 넣지 않음 | 사용자가 가진 파일만 업로드해서 편집 |

## 7. 재사용 가능한 자산

- **얼굴 모자이크**: [[salpim-on]](살핌ON)에서 MediaPipe Face Detector 기반 얼굴 자동 모자이크를 이미 다뤘다. 검출·모자이크 렌더 로직은 그대로 모듈로 떼어와서 영상 프레임 루프에 붙이면 된다. 신규 개발은 "프레임 간 얼굴 ID 추적"과 "인물별 예외 처리" 부분만 하면 된다.
- **`○○ON` 네이밍**: 기존 프로젝트 계열(시설ON·준공ON·오픈ON·미러ON·살핌ON)과 맞춰 **편집ON**으로 명명한다.

| 리스크 | 영향 | 확률 | 대응 |
|---|---|---|---|

## 9. 릴리스 계획 요약

| 마일스톤 | 내용 | 산출물 |
|---|---|---|
| M0 | 기술 검증 (스파이크) | ffmpeg.wasm 인코딩 성공, OPFS 저장 성공 |
| M1 | 편집기 뼈대 | 업로드 → 수동 컷 → 내보내기 (E2E 성립) |
| M2 | 자동 컷 편집 | 무음 감지 + 추임새 제거 |
| M3 | 자막 | STT → 2단계 편집 → 스타일 → 번인 |
